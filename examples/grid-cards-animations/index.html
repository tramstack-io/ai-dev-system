Design that feels effortless

Apple-style Feature Grid

Responsive 2x2 grid on desktop/tablet, collapsing to a single column on mobile. Each card opens an accessible modal with more information.

Features

Hover a card for a subtle GSAP interaction. Keyboard users get the same feedback.

Privacy first

Clear, user-first privacy reduces friction and builds trust. This dialog demonstrates an accessible, focus-trapped modal pattern.

  • Keyboard-first interaction and visible focus.
  • Respectful defaults and transparent UI.
  • Motion that can be disabled via reduced-motion.

Seamless performance

Micro-interactions should feel smooth and intentional. The hover effect uses a small GSAP transform for an “Apple-like” lift.

  • Subtle GSAP hover: translate up + slight scale.
  • Same feedback on keyboard focus.
  • Reduced motion supported.

Design tokens

Tokens help keep visual language consistent: spacing, radius, typography, and color all stay aligned across the UI.

  • Rounded surfaces and subtle borders.
  • Rhythm via consistent spacing steps.
  • Contrast that stays readable.

Sync everywhere

Consistency across breakpoints matters. This layout uses CSS Grid and maintains the 2x2 structure on desktop/tablet while stacking on mobile.

  • 2 columns on mobile? No: single column stack.
  • 2 columns on tablet/desktop for a 2x2 grid.
  • Accessible focus behavior everywhere.
