# AI Dev System — Overview

## Purpose
This repository is a structured AI-assisted frontend development system.

It is designed to:
- improve consistency
- increase speed of development
- make knowledge reusable
- reduce ad-hoc or one-off solutions

---

## Core Idea

This is not just a code repository.

It is a **system for building, storing, and reusing frontend knowledge**.

The system separates:

- Patterns → how things should be built  
- Workflows → how work is done  
- Examples → real implementations  

---

## How the System Works

The workflow is:

Think → Build → Store → Reuse

### 1. Think
Use AI (ChatGPT / Claude) to:
- break down problems
- define structure
- plan solutions

---

### 2. Build
Use Cursor to:
- create components
- implement layouts
- test ideas

---

### 3. Store
Capture reusable outputs as:
- patterns (rules)
- workflows (process)
- examples (reference)

---

### 4. Reuse
Apply stored knowledge to:
- new components
- new projects
- real-world work (e.g. Liberty)

---

## Tool Roles

- ChatGPT → thinking, structuring, planning  
- Claude → deep reasoning, system refinement but also thinking, structuring, planning (future phase)  
- Cursor → execution and code generation  
- GitHub → system memory and version control
