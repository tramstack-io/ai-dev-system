# Folder Roles

| Folder | Purpose |
|---|---|
| ai-dev-system | Reusable intelligence and system memory |
| projects | Real-world outputs and products |
| experiments | Safe exploration and temporary testing |
| archives | Paused or inactive material |
| workspaces | Operational workspace entry points |

---

# Core Rule

Reusable thinking becomes markdown.

Temporary thinking can stay in chats.

Real outputs become projects.

Experiments stay separate.
