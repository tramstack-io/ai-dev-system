# Work OS MVP

## Purpose

A lightweight visual MVP that explains how I think about my role through systems, not just tasks.

This page is designed to support:

* performance review conversations
* salary alignment discussions
* clearer communication of my value
* a more strategic explanation of how I work

It is not a portfolio piece or a polished product. It is a working visual narrative.

---

## Audience

Primary audience:

* manager
* senior stakeholders
* performance review context

Secondary audience:

* myself, as a structured way to explain my role and growth direction

---

## Core Idea

The Work OS page turns my role into a **system narrative**.

Instead of only showing:

* tasks completed
* projects touched
* tools used

It shows:

* how I think
* how I execute
* how I use AI intentionally
* how systems connect to measurable impact

---

## Interaction model

This MVP uses a clean summary-first layout.

Each pill contains:

* a short title
* a one-line description
* a click-to-reveal note

Purpose of the note layer:

* support presentation flow
* act as built-in speaker notes
* keep the page clean by default
* reveal depth only when needed

This makes the page useful both as:

* a visual summary
* a guided discussion tool

---

## Design approach

The design is intentionally:

* lightweight
* modern
* clean
* stakeholder-friendly

Key UI choices:

* light theme
* rounded pill navigation
* soft borders
* coloured dots for hierarchy and scannability
* expandable note states for presentation use

This keeps the page feeling structured and calm rather than overloaded.

## What this MVP is not

This page is not:

* a full dashboard
* a final internal product
* a complete documentation system
* a replacement for evidence or examples

---

## Suggested use in a 1:1

Use the page to guide conversation in this order:

1. Overview
2. Career OS
3. AI System
4. Performance
5. Workflow
6. Outcome

Only expand notes selectively.

The goal is not to click everything.
The goal is to use the expandable notes when a point needs deeper explanation.
