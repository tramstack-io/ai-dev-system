# Claude → Cursor → GitHub Workflow

## Purpose

This workflow defines the standard operational flow for AI-assisted frontend and systems work.

The goal is to reduce fragmentation and create repeatable execution patterns.

---

# Core Workflow

```text
Think
→ Build
→ Store
→ Reuse
```

---

# Stage 1 — Think

Primary tools:
- ChatGPT
- Claude

Purpose:
- architecture thinking
- planning
- workflows
- systems reasoning
- problem solving
- frontend strategy
- AI coordination

Outputs:
- decisions
- plans
- prompts
- workflows
- markdown drafts

Important:
Temporary thinking can stay in chats.

Reusable thinking must become markdown.

---

# Stage 2 — Build

Primary tools:
- Cursor
- Claude Code
- Warp

Purpose:
- implementation
- coding
- editing
- terminal operations
- experimentation
- frontend development

Typical flow:

```text
Warp
→ open workspace
→ Cursor
→ Claude assistance
→ local testing
```

---

# Stage 3 — Store

Primary tool:
- GitHub

Purpose:
- reusable memory
- version history
- documentation
- workflow preservation
- system continuity

Typical flow:

```bash
git status
git add -A
git commit -m "Clear commit message"
git push origin main
```

---

# Stage 4 — Reuse

Reusable knowledge gets stored inside:

```text
ai-dev-system/
```

Examples:
- workflows
- patterns
- snippets
- context packs
- cheatsheets
- architecture notes

This creates:
- compounding knowledge
- reduced repeated thinking
- reusable AI context
- operational clarity

---

# Workspace Philosophy

The workspace is the operational environment.

```text
personal-ai-os.code-workspace
```

should become the daily starting point.

The goal is:
- fewer random tabs
- less cognitive switching
- cleaner operational flow
- stronger focus

---

# Important Principles

## AI tools are not the system

The workflow is the system.

---

## Reusable thinking belongs in markdown

Chats are temporary.

Markdown becomes operational memory.

---

## Projects stay separate from intelligence

| Type | Location |
|---|---|
| Reusable intelligence | ai-dev-system |
| Real outputs | projects |
| Exploration | experiments |
| Inactive work | archives |

---

# Long-Term Goal

Build a scalable AI-native frontend development workflow that supports:

- deep thinking
- fast execution
- reusable systems
- portfolio growth
- AI-assisted creativity
- reduced cognitive overload
